## 📝 Опис

Doc2Sheet — це інструмент для швидкої оцифровки паперових документів. Завантажте фотографії однотипних документів, і застосунок автоматично:

1. Визначить структуру документа (поля/колонки)
2. Розпізнає текст з кожного фото
3. Створить структуровану таблицю
4. Дозволить редагувати, сортувати та експортувати дані

## ✨ Можливості

### 📸 Розпізнавання документів
- Завантаження фото через камеру або галерею
- Підтримка drag-and-drop
- Обробка кількох фото одночасно
- Автоматичне визначення структури з першого фото
- Розпізнавання друкованого та рукописного тексту
- Підтримка української мови

### 📊 Робота з таблицею
- Редагування клітинок безпосередньо в браузері
- Додавання та видалення рядків і колонок
- Перетягування рядків та колонок для сортування
- Візуальна індикація якості розпізнавання
- Історія змін (undo/redo)

### 💾 Експорт даних
- **Excel** (.xls) — сумісний з Microsoft Excel
- **Word** (.doc) — відкривається в Microsoft Word
- **CSV** (.csv) — універсальний формат

### 🔒 Безпека
- API ключ зберігається лише в пам'яті вкладки
- Без localStorage та cookies
- Без відправки даних на сервер (окрім Google API)
- Автоматичне очищення при закритті сторінки
